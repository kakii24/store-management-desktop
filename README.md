# 🖥️ Store Manager Desktop

A desktop management app for a computer store built with Electron + React + SQLite.

## Features
- 📦 Inventory management (computers, phones, parts)
- 🔧 Repair orders tracking
- 💰 Income & expenses tracking
- 💱 Currency trading (USDT, EUR)
- 📊 Dashboard with totals and charts

## Tech Stack
- Electron
- React + Vite
- Tailwind CSS
- SQLite (better-sqlite3)

## Run locally
npm install
npm run dev  # Terminal 1
npm run start  # Terminal 2
